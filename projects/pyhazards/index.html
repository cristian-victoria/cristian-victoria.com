Case 03ML engineeringJan — May 2026PyTorchDept. of Scientific Computing, FSU

Two published models, rebuilt to run inside a lab's library.

As a research assistant in FSU's Department of Scientific Computing, I reproduced two deep-learning architectures from recent papers in the lab's PyTorch framework, PyHazards: WaveCastNet, which forecasts earthquake wavefields, and DLWP, which predicts weather on a cubed sphere.

Each is registered so other researchers can use it in their own experiments. A test harness I built checks every model in the registry before it reaches an experiment, and I documented the paper-to-library workflow for whoever adds the next one.
