HOW TO ADD WRITING CONTENT
==========================

Drop files into this folder for each essay or piece:

- One .txt file per essay (the full essay text in plain prose)
- Any .png or .jpg images if relevant

File naming: use the essay slug as the filename.
  Example: on-curiosity.txt

When you add new files, ask Claude to read them and update the HTML pages.

TXT format: write the essay naturally. Start with the title on the first line,
then a blank line, then the body. No special formatting required — Claude will
handle the structure.
