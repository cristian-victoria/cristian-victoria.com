HOW TO ADD WORK CONTENT
=======================

Drop files into this folder for each project:

- One .txt file per project (plain prose describing the project)
- Any .png or .jpg images for the project

File naming: use the project slug as the filename.
  Example: my-ai-project.txt, my-ai-project-hero.png

When you add new files, ask Claude to read them and update the HTML pages.

TXT format: just write naturally — what the project is, what you built,
what problem it solved, what technologies you used, and what the outcome was.
No special formatting required.
