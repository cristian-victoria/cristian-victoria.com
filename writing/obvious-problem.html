The Most Interesting Problem Is Never the Obvious One

November 2025

Every organization I've worked with has the same pattern: the problem they're trying to solve isn't the problem worth solving. The real one is usually one layer deeper, hiding behind the obvious pain point like a second door behind the first.

This isn't incompetence. It's a structural feature of how organizations perceive problems. The visible problem is visible precisely because it's already been named — it has a budget line, a team, a set of metrics. The invisible problem is invisible because no one has had the slack to articulate it yet.

The skill I've spent years developing is diagnosis before prescription. It sounds obvious, but most consulting engagements skip this step. They arrive with a solution looking for a problem. The client, eager to appear decisive, accommodates them. Both parties feel productive. Nothing important changes.

The tell is usually in what everyone agrees on without discussion. Consensus in the absence of debate is often the surface of a deeper disagreement that's been tabled so many times it's become invisible. Those are the best places to start looking.

When I find the real problem, it's rarely dramatic. It doesn't feel like a discovery — it feels like a relieved exhale. "Oh, that's what's actually going on." The solution, once the problem is correctly defined, is usually straightforward. The hard part was always the seeing.
