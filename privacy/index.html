Privacy Policy

Effective October 8, 2026. This policy covers Sohana, a personal assistant app built and used by Cristian Victoria. Sohana is not offered to the public. It connects only to Google accounts that Cristian owns and signs in to himself.

What Sohana accesses

When a Google account signs in, Sohana requests access to that account's Gmail (and, if added later, Google Calendar). It uses this access only to read, search, and organize that account's email and calendar when its owner asks it to. Sohana can also send or delete email, but only after the account owner approves each action.

Sohana also receives the signed-in account's basic profile (name and email address) so it can confirm which account is connected.

How data is stored

Sohana runs on its owner's own computer. Sign-in tokens and any email exports are stored in files on that computer. Sohana has no server or database of its own and does not copy email anywhere else.

What Sohana never does

Sohana does not sell, rent, or share Google user data with anyone. It does not use Google user data for advertising, and it does not use it to train or improve AI or machine learning models.

Sohana's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Any connected account can revoke Sohana's access at any time from Google Account permissions. Revoking access stops Sohana from reading that account immediately, and its locally stored sign-in token stops working.
